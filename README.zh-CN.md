#### 关于插件
- Neo+是[Neo主题](https://github.com/QYLexpired/Neo)的配套插件，为Neo主题提供配色和样式扩展，仅在使用Neo主题时生效
- 插件不向文档写入或修改任何数据，仅进行外观修改，可随时启用或卸载而不影响任何笔记内容
- 插件内所有功能/特性都具有完整的生命周期，仅在开启时消耗性能，其中部分特性对性能消耗可能较大，需根据设备情况选择性开启
- 更多说明可查看Neo主题介绍页
#### 关于主题
- **Neo主题**：Neo是专为思源笔记设计的第三方主题，设计风格高度参考Apple HIG（macOS/iOS），以全局统一、细致打磨的界面语言，让每次笔记体验都赏心悦目
- **依赖Neo+插件**：主题的部分样式和功能无法仅通过CSS实现，因此必须安装并启用本插件
- **问题反馈**：使用过程中有任何问题或建议，可通过[Neo 主题介绍及反馈综合帖](https://ld246.com/article/1783158376401)或[GitHub](https://github.com/QYLexpired/Neo/issues)进行反馈
- **支持我**：Neo主题是完全免费的，如果喜欢这个主题，欢迎在[GitHub](https://github.com/QYLexpired/Neo)为我点亮小星星，也可以[请我喝杯咖啡](https://icnmjy02sv9g.feishu.cn/wiki/FekNwrtB7ia1WckYelRckwzZnig?from=from_copylink)
