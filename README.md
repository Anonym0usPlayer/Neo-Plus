#### About Neo+ Plugin
- Neo+ is a companion plugin for the [Neo theme](https://github.com/QYLexpired/Neo), providing color schemes and style extensions for the Neo theme. It only takes effect when using the Neo theme.
- Neo+ does not write or modify any document data; it only makes appearance modifications, and can be enabled or uninstalled at any time without affecting any note content.
- All features within the plugin have a complete lifecycle and only consume performance when enabled. Some features may have a significant performance impact and should be selectively enabled based on your device's performance.
- For more details, please see the Neo theme introduction page.
#### About Neo Theme
- **Neo Theme**: Neo is a third-party theme designed specifically for SiYuan Notes, with a design language highly inspired by Apple HIG (macOS/iOS). Its globally unified, meticulously polished interface makes every note-taking experience a pleasure.
- **Depends on the Neo+ plugin**: Some of the theme's styles and features cannot be implemented with CSS alone, so this plugin **MUST** be installed and enabled.
